# Concall Analyser

Automated analyser for the **earnings call (concall) transcripts** of NSE-listed
companies with a market capitalisation of **₹5,000 crore or more**.

It downloads each company's latest concall transcript, scans the text for a
curated set of investment-signal keywords (and their synonyms and tone),
ranks each company by how many signal categories it hits, captures the exact
supporting quotes, and exports a prioritised Excel report.

## What it does

1. **Build the universe** — pulls the full NSE equity list and filters to
   companies with market cap ≥ ₹5,000 cr.
2. **Fetch transcripts** — downloads the latest concall PDF from Screener.in,
   falling back to the NSE/BSE filings when Screener doesn't have it.
3. **Parse** — extracts text from each PDF.
4. **Score** — matches the text against an 11-category keyword dictionary
   (see below). Each category counts once, regardless of how many synonyms
   appear, and the surrounding sentence is captured as the supporting quote.
5. **Rank & export** — assigns a High / Medium / Low priority by the number of
   categories matched and writes a formatted Excel workbook.

## Signal categories

High Growth / Topline · Order Visibility · Margin Expansion · Capacity
Expansion · Integration & Efficiency · Market Share · Deleveraging · Cash
Generation · Working Capital · Return Ratios · Corporate Action

## Setup

```bash
pip install -r requirements.txt
```

Requires Python 3.9+.

## Usage

```bash
python analyser_final.py
```

Configuration lives near the top of `analyser_final.py` — market-cap floor,
priority thresholds, output paths, and the keyword dictionary are all easy to
edit. Outputs are written to a `concall_output/` folder (created on first run).

## Sample output

[`concall_output/Final Output.xlsx`](concall_output/Final%20Output.xlsx) is a
sample report so you can see the format without running the full pipeline.

> **Note:** the downloaded transcript PDFs (~4.8 GB) and intermediate run files
> are intentionally **not** committed — they are regenerated by the script.

## Disclaimer

This is a research/screening tool, not investment advice. Transcript data is
sourced from public filings on Screener.in and NSE/BSE. Be mindful of the rate
limits and terms of use of those sites.
